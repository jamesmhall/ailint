# AIL106: detect-instruction-bloat

**Category**: [Semantic](README.md)  
**Default Severity**: `Warning`

## Overview
Warns when a top-level prose paragraph exceeds 120 words. List items and
fenced code blocks are ignored (see [AIL102](AIL102.md) for the per-list-item
budget).

## Why it matters
Agents disproportionately skim or paraphrase away long, monolithic paragraphs
— exactly the paragraphs that most often carry critical constraints. A single
sprawling paragraph is nearly always a collection of separate directives that
should each stand on its own line.

## How to fix it
Break the paragraph into shorter statements or a bulleted list. If the
paragraph is genuinely a single argument that needs the prose form, split it
into two or more paragraphs at natural boundaries.

## Configuration

```yaml
rules:
  options:
    detect-instruction-bloat:
      max_words: 200      # override default of 120
```
