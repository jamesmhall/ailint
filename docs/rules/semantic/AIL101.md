# AIL101: no-missing-examples

**Category**: [Semantic](README.md)  
**Default Severity**: `Info`

## Overview
Identifies sections with the header `Examples` that do not contain actual code blocks (e.g. content wrapped in ` ``` `).

## Why it matters
Providing a section named Examples without actually taking the time to illustrate the example inside a fenced code block does not give the LLM the high-fidelity syntactical context it needs to adopt your pattern.

## How to fix it
Implement the examples using Markdown fenced code block syntax.
