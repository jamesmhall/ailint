# AIL103: no-duplicate-rules

**Category**: [Semantic](README.md)  
**Default Severity**: `Info`

## Overview
Detects multiple bulleted instructions inside the same file that are semantically identical or nearly identical overlapping strings.

## Why it matters
Duplicating a rule in the same file wastes LLM tokens and creates cognitive noise. It often signals that a file has been organically appended to without reviewing the prior contents.

## How to fix it
Locate the line item mentioned in the report, and remove it or merge its nuance back into the original matching rule it collided with.
