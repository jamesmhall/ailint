# AIL105 `vendor-optimization-syntax`

Anthropic's official models (like Claude) perform best when instructions are explicitly delineated using XML tags. When creating instruction files for Anthropic-hosted agents (like `CLAUDE.md` or `.clinerules`), failing to use XML structure creates suboptimal execution.

## Why this is bad
Without XML boundaries, Claude may struggle to parse where context ends and rules begin, specifically in long system prompts.

## How to fix it
Wrap the core operating procedures in standard XML tags such as `<conventions>`, `<examples>`, or `<rules>`.

```markdown
<!-- Bad -->
Here are the rules to follow:
1. Always use functional components.

<!-- Good -->
<conventions>
1. Always use functional components.
</conventions>
```
