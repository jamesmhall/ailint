# AIL102: excessive-rule-length

**Category**: [Semantic](README.md)  
**Default Severity**: `Warning`

## Overview
Warns if a single rule (often defined as a single list-item) contains over 60 words.

## Why it matters
LLMs suffer from the "lost in the middle" problem. An ultra-dense, paragraph-length list item usually contains multiple directives mashed together. An agent is statistically more likely to drop portions of instructions if they are not atomic.

## How to fix it
Break the single sprawling rule into multiple cohesive, single-purpose bullet points, or move elaborate context out of the bullet items and into a dedicated prose section / example block below.
