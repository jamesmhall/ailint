# AIL301: no-duplicate-guidance-files

**Category**: [Consistency](README.md)  
**Default Severity**: `Info`

## Overview
A cross-file processor that fingerprints the entire contents of a file (stripping markdown chrome, casing, and frontmatter) and warns if it matches another file in the workspace exactly.

## Why it matters
Scaffolding tools often generate multiple files (e.g. `AGENTS.md` and `.cursorrules` and `CLAUDE.md`) containing the exact same stuff during project init. This wastes context tokens and forces developers to update 3 files every time a single architecture pipeline changes. 

## How to fix it
Delegate. Choose a single source of truth (e.g. `AGENTS.md`). Place the actual content there. In the other files, write a single line: `Full context: [AGENTS.md](AGENTS.md).` Your AI agents will read the pointer and pull the centralized rules.
