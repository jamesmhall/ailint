# AIL300: no-conflicting-rules

**Category**: [Consistency](README.md)  
**Default Severity**: `Warning`

## Overview
A cross-file processor that fingerprints the normalized syntax of your workspace's rule items and looks for direct negations across *different* files.

## Why it matters
If `CLAUDE.md` says "Use tabs", but an obscure `.cursor/rules/formatting.mdc` says "Never use tabs", the agent receives contradictory context. This causes the models to act unpredictably or constantly thrash their code generation. 

## How to fix it
Find the two conflicting files noted in the violation output. Decide the single source of truth, remove the contradiction from the other, or scope their globs/contexts so they do not overlap.
