# AIL900: llm-quality-score

**Category**: [LLM](README.md)  
**Default Severity**: `Warning`

## Overview
This is a powerful opt-in LLM rule. When `AIL900` is activated (by setting the `llm` block in `.ailint.yaml`), the tool halts static parsing, packages the file contents in a specialized [quality_system.md](../../../crates/ailint-llm/prompts/quality_system.md) prompt, and shoots it out to the provider (OpenAI, Anthropic, Google, Ollama, etc.).

## Why it matters
Static analysis via regex and string metrics is good, but actually having a frontier model read the instructions and grade them for logical contradictions, massive gaps in context, and clarity is the peak of AI alignment engineering.

## How to fix it
The output from this rule is dynamic. Read the violation output provided by the LLM and action directly on its critique. It will typically tell you exactly where the instruction file is failing to pass the context an agent requires.
