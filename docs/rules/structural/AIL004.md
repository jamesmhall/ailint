# AIL004: mcp-schema-validation

**Category**: [Structural](README.md)  
**Default Severity**: `Error`

## Overview
Validates the minimum viable schema of Model Context Protocol server config
files: `mcp.json`, `.mcp.json`, `.cline_mcp.json`, or `mcp.json` nested under
`.cursor/` or `.vscode/`.

## Why it matters
A broken MCP config silently disables tool access at agent startup — the
agent then hallucinates that the tool doesn't exist, or worse, invents
plausible-looking output that was never sourced from the real tool.

## What it checks
- Root value is a JSON object.
- The root has an `mcpServers` (Claude / Cline / Cursor) or `servers`
  (VS Code) object, and it isn't empty.
- Each server entry:
  - Declares a transport: either `command` (stdio) or `url` (http / sse).
  - `command`, if present, is a string.
  - `url`, if present, is a string.
  - `args`, if present, is an array of strings.
  - `env`, if present, is an object with string values.

## How to fix it
Give every server a `command` (stdio) or `url` (http/sse). If you were
using shorthand, expand it into the documented object form.

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    }
  }
}
```
