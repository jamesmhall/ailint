# AIL003: missing-required-section

**Category**: [Structural](README.md)  
**Default Severity**: `Warning`

## Overview
Ensures that a guidance file contains standard, mandatory Markdown sections. By default it enforces that an `## Examples` (or `Examples`) section is present.

## Why it matters
Agents learn far quicker from specific concrete positive and negative outputs than from paragraphs of vague prose. The lack of an example section is highly correlated with abstract, poorly followed guidelines.

## How to fix it
Create an `## Examples` section (casing is ignored) and provide code blocks illustrating what *to* do, and what *not* to do.
