# AIL002: instructions-file-empty

**Category**: [Structural](README.md)  
**Default Severity**: `Warning`

## Overview
Warns if a defined guidance file has a length of zero, or contains only blank whitespace / newlines.

## Why it matters
Empty files just clutter the context window and the file system structure without guiding the agent. Leaving an empty `.instructions.md` signals a missed setup or broken scaffolding process.

## How to fix it
Populate the file with the guidelines the agent needs, or if it isn't necessary, delete the empty file.
