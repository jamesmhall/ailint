# AIL001: no-frontmatter-schema-error

**Category**: [Structural](README.md)  
**Default Severity**: `Error`

## Overview
Checks that the `.mdc` or generic markdown files contain valid structured YAML frontmatter at the top of the file.

## Why it matters
Files like `.cursor/rules/*.mdc` depend completely on frontmatter specifying their `description` and `globs`. If the frontmatter is incorrectly typed, not true YAML, or misses the `---` blocks, the system fails to apply the agent targeting.

## How to fix it
Locate the error at line 1, column 1 of the file and ensure the block at the top looks like the example below, strictly formatted as valid YAML.

```yaml
---
description: Explain what this rule governs
globs: "**/*.js"
alwaysApply: false
---
```
