# AIL201: no-unrestricted-tool-grant

**Category**: [Security](README.md)  
**Default Severity**: `Warning`

## Overview
Detects instructions granting an agent universal sweeping permissions (e.g. "You have access to all tools", "Run any command without asking").

## Why it matters
Auto-execution rules should be bound. Giving an agent sweeping authority to hit the shell without asking creates environments where a hallucination triggers destructive operations (like dropping tables, or wiping directories).

## How to fix it
Scope auto-execution to safe spaces (e.g. "You may run `npm test` automatically"). And explicitly mandate asking for confirmation for destructive commands, or leave the default human-in-the-loop fallback intact.
