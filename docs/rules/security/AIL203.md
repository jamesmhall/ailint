# AIL203 `tool-confirmation-required`

When an instructional prompt describes potentially destructive operations (e.g., dropping databases, deleting files, executing `rm -rf`), it is critical to explicitly require the agent to seek human approval before taking action.

## Why this is bad
Fully autonomous execution of irreversible or destructive actions without human-in-the-loop validation can cause data loss or system corruption.

## How to fix it
Include clear constraints demanding confirmation alongside the destructive action.

```markdown
<!-- Bad -->
When cleaning up the workspace, use `rm -rf` to remove old build artifacts.

<!-- Good -->
When cleaning up the workspace, ask for human permission before using `rm -rf` to remove old build artifacts.
```
