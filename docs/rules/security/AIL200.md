# AIL200: no-prompt-injection-marker

**Category**: [Security](README.md)  
**Default Severity**: `Error`

## Overview
Detects prompt-injection terminology (e.g. "Ignore previous instructions", "Disregard all instructions", "You are now an").

## Why it matters
Using these markers in core architectural agent files is a massive security risk. It creates vectors where malicious prompt text (found in scraped data, issues, or rogue code) can hijack your agent's system-level context. Legitimate overrides should be structured via configuration or scope, not via aggressive instruction masking which introduces unpredictability to the agent alignment constraints.

## How to fix it
Never attempt to "jailbreak" an agent inside a system-level `.md` instruction file. State the actual parameters the agent should abide by declaratively.
